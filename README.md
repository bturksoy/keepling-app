# Keepling — website

The public page for **Keepling: Baby Memory Journal**, served by GitHub Pages at
<https://bturksoy.github.io/keepling-app/>.

It exists partly because Google's OAuth consent screen requires an application
home page before it will let the app publish, and partly because the app
deserved somewhere to point at.

- `index.html` — the whole page; no build step, no dependencies
- `assets/` — app icon and screenshots, copied from the app repo's `store/`

The privacy policy lives separately, at
<https://bturksoy.github.io/keepling-privacy/>.

To change something, edit `index.html` and push to `main` — Pages redeploys on
its own within a minute or so.
